# web-grab — صور المنتج من أي رابط

جهاز Claude ما يوصلش لأغلب المواقع (المتاجر، AliExpress، eBay...). سيرفر GitHub يوصل.
تبعث رابط صفحة منتج من الهاتف، و Claude يجيب الصور الكبار تاع المنتج ويحطهم في Drive.

| الأمر | شنو يدير |
|---|---|
| `images <رابط الصفحة> [--max 15] [--min-side 600]` | يجيب صور المعرض تاع المنتج بأكبر جودة، يحيّد الأيقونات والصور الصغار والمكررة |
| `file <رابط صورة>` | يحفظ صورة وحدة |

```
# مباشرة من جلسة Claude، كي يكون الموقع (والسيرفر تاع الصور تاعو) مفتوح في البيئة:
python3 tools/web-grab/grab.py --request-file req.txt --out out/
# ولا عن طريق GitHub:
tools/remote/job.sh web-grab 'images https://example.com/product.html'
```

مواقع كبار كيما eBay وAmazon وAliExpress ساعات يرفضو التحميل الأوتوماتيكي (403).

كل صورة تخرج JPEG، أكبر جانب 2000 بيكسل، أقل من 3 ميغا (باش تدخل لـ Drive).

ملاحظة: صور المورّد ولا الماركة تاع نفس المنتج اللي تبيعو عادة مقبولة. صور متجر آخر
صوّرها بروحو هي ملكو. والأحسن ديما صورك أنت.
