# product-reel — ريل من صورة منتج وحدة

يصنع ريل 9:16 (1080×1920، 30fps) من صورة منتج وحدة بخلفية بيضاء: الكاميرا تتحرك على
تفاصيل المنتج، كروت كتابة بالدارجة، وبطاقة نهاية بالسعر. الكتابة كاملة داخل المنطقة
الآمنة تاع إنستغرام وتيك توك (y من 230 حتى 1440، و230 بيكسل على اليمين فارغين).

أول مثال: كوك آيفون ميتال (2026-11-27).

## الاستعمال

```bash
cd tools/product-reel
npm install                      # خط Cairo
cp /path/to/photo.png product.png   # صورة مربعة 1080×1080، خلفية بيضاء
# عدّل في compose.html: نصوص الكروت (#c0..#c5)، بطاقة النهاية (#end)،
# ونقاط الكاميرا CAM [وقت، x، y، زوم] بإحداثيات الصورة.
python3 music.py music.wav       # موسيقى أصلية: 8 مقاطع (bars)، 109 BPM، كل bar = 2.2 ثانية
node render.js . 17.6 30 music.wav   # يخرّج reel.mp4 بالموسيقى (بلا music.wav يخرج بلا صوت)
```

`render.js` يرسم كل فريم بـ Chromium (Playwright) ومن بعد ffmpeg يركّبهم ويوازن الصوت
على -14 LUFS. `music.py` (يحتاج numpy وscipy) يصنع موسيقى من الصفر، بلا حقوق: kick،
clap، hats، bass، أكوردات Am-F-C-G، مع "تيك" معدني في البداية، riser قبل كل قطعة،
وضربة كي تبان بطاقة السعر (`--impact-bar`).

كل لقطة في `compose.html` = bar واحد (2.2 ثانية)، والقطعات على الضربة. إذا بدّلت عدد
اللقطات، بدّل `--bars` باش الموسيقى والفيديو يدوروا مع بعض.

## وضع الصور المتعددة (`compose-slides.html`)

كي يكون عندك بزاف صور (صور المورّد مثلاً): كل لقطة = صورة وحدة، تتقص منها منطقة
(`crop: [x0, y0, x1, y1]` بإحداثيات الصورة) وتبان في إطار مدوّر فوق نسخة مضبّبة من
نفس الصورة. القص يخلّيك تحيّد الكتابة الصينية تاع المورّد. حط الصور في `img/`، عدّل
`SCENES`، ومن بعد:

```bash
cp compose-slides.html compose.html
python3 music.py music.wav --bars 9 --impact-bar 7   # 7 لقطات + بطاقة سعر (2 bars)
node render.js . 19.8 30 music.wav
```

أول مثال: صور المورّد تاع كوك آيفون ميتال من Alibaba (2026-11-27).
